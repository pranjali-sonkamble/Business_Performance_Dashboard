# Business Performance Dashboard

## Overview
This project is an end-to-end business performance analysis built using retail sales data.
The goal of this project is to demonstrate practical data analytics skills, from data cleaning
to dashboard creation and business insight generation.

## Dataset
- Online Retail Dataset (transaction-level retail sales data)
- The full dataset is large in size, so it is not uploaded to this repository
- A Power BI dashboard and screenshots are provided for analysis and insights

## Tools Used
- Excel – data cleaning and feature creation
- Power BI – data modeling, DAX measures, and dashboard visualization

## Business Questions Answered
- What is the total sales revenue?
- How do sales trend over time?
- Which products generate the highest revenue?
- Which countries contribute the most to sales?
- Are there periods of sales decline or growth?

## Key Insights
- Total revenue is generated from a high volume of orders with a moderate average order value.
- Sales show an overall upward trend, with strong growth toward the end of the year.
- Revenue is concentrated among a small group of top-performing products.
- The United Kingdom contributes the majority of total sales revenue.
- When excluding the UK, a few international markets show potential for future growth.
